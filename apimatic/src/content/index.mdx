## Architectural Principles: The Ledger of Trust

Every interaction in ResolvePay Rescue is anchored by strict operational invariants:

1. **Replacement Before Refund**: Policy proposals proactively offer product exchanges, replacement shipments, or store credit before resorting to punitive cash refunds.
2. **Physical Inspection Gates**: High-value returns require verifiable tracking milestones and explicit warehouse condition checks before remedy escrow funds unlock.
3. **Double-Entry Subledger Reconciliation**: Every financial mutation generates balanced debit and credit entries with cryptographic idempotency keys, eliminating reconciliation drift.
4. **Deterministic Invariant Enforcement**: State transitions are strictly verified against merchant policy thresholds, evidence completeness scores, and dispute timelines.

## Quickstart: Installing the SDK

Choose your preferred programming language to integrate ResolvePay Rescue:

### TypeScript / Node.js

```bash
# In your project root
npm install ./apimatic/sdks/typescript
```

```typescript
import { ResolvePayRescueApiClient } from "resolve-pay-rescue-api";

const client = new ResolvePayRescueApiClient({
  bearer: process.env.RESOLVEPAY_API_TOKEN,
});

// Fetch active dispute cases
const cases = await client.cases.listCases();
console.log(`Open cases: ${cases.length}`);
```

### Python

```bash
# In your virtual environment
pip install ./apimatic/sdks/python
```

```python
from resolvepay_rescue_api import ResolvePayRescueApiClient

client = ResolvePayRescueApiClient(
    bearer="YOUR_API_TOKEN"
)

# Fetch merchant dispute policies
policies = client.policies.getMerchantPolicies()
print(f"Active policy tier: {policies.active_version}")
```

### C# / .NET

```csharp
using ResolvePayRescueApi;

var client = new ResolvePayRescueApiClient(
    bearer: Environment.GetEnvironmentVariable("RESOLVEPAY_API_TOKEN")
);

var recoveryStats = await client.Merchant.GetMerchantRecoveryMetricsAsync();
Console.WriteLine($"Net Salvaged Volume: ${recoveryStats.SalvagedVolumeUsd}");
```
